# 📊 銀行定存行銷轉換率分析與決策最佳化專案 
> **專案定位**：基於行為特徵與互動歷史之銀行定存轉換率分析，透過 Python 探索性數據分析（EDA）與機器學習決策樹驗證，協助金融機構解決亂槍打鳥的高成本痛點，實現精準獲客。

---

## 一、 專案背景與商業價值
* **商業痛點**：定期存款為銀行穩健利息收入的核心來源，但傳統電話行銷高度依賴大量人工外撥，伴隨高昂的營運成本與資源浪費。
* **核心目標**：透過資料探勘與行為分析，在行銷活動前識別高轉換潛力的客戶，將亂槍打鳥轉化為精準鎖定，大幅降低獲客成本並最大化轉換效率。

---

## 二、 四大核心數據洞察 (Key Insights)

| 分析維度 | 核心發現與數據指標 | 商業價值與解讀 |
| :--- | :--- | :--- |
| **1. 先前行銷成效 (`poutcome`)** | 成功舊客轉換率高達 **64.7%** ($n=1,511$) | 過去有良好互動經驗的舊客黏著度極高，是預測未來行為最強的指標。 |
| **2. 行銷通話頻次 (`campaign`)** | 最佳效益落在 **1 至 3 通**，第 4 通起顯著遞減 | 證實「非以量制勝」，過多的行銷反而失去效率。 |
| **3. 黃金追蹤期 (`pdays`)** | 成功轉換高峰集中在距離上次接觸 **50 至 200 天** | 掌握最佳回訪時間窗，超過 250 天後轉換率與密度大幅下滑。 |
| **4. 聯絡管道選擇 (`contact`)** | 行動電話（`cellular`）轉換率達 **14.9%** 表現最佳 | 樣本數高達 29,285 筆，確立行動裝置為最有效行銷管道。 |

## 三、 機器學習決策樹收斂模型
為了在數學上印證上述 EDA 洞察，本專案建構了一座 **3 層決策樹模型**，其邏輯架構與專案結論完美契合：
* **第一層（根節點）**：由 **`poutcome_success`** 領軍，直接區分出過去曾成功申辦的高價值舊客群（轉換率 64.7%）。
* **第二層（中層切分）**：導入 **`gold_pdays`（50至200天黃金追蹤期）** 與 **`housing`（房屋貸款負擔狀況）**，過濾出具備良好現金流與黃金跟進期的潛在客戶。
* **第三層（底層收斂）**：帶入 **`optimal_campaign`（3通電話以內）**，在末端精準收斂出邊際效益遞減的邊界條件。

## 四、 具體營運策略與落地建議 (Actionable Strategies)
1. **建立 VIP 優先外撥名單（VIP Queue）**：
   * 將符合「前次行銷成功」且「無客訴紀錄」之舊客自動歸類，指派資深業務專員優先對接，確保優質體驗。
2. **導入自動化停損機制（Automated Stop-Loss）**：
   * 當同一客戶在單次活動中被拒絕達 2 次（或超過最佳通話次數），系統自動將其移出外撥名單，改由成本較低的簡訊或網銀通知跟進，避免業務人員在抗拒度高的名單上消耗工時。
3. **客群細分與個人化行銷**：
   * 定期透過特徵工程更新標籤，依據年齡、資產分級與互動頻率，自動派送對應的溝通腳本（Script），實現成效閉環監控。
